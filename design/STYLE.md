기준 이미지: `design/reference.png` (상권 매출 요인 — 비교 메인 구상안)
실제 스타일 값: `design/theme.css` (앱이 이 파일을 그대로 읽음)

## 2. 글자

- 글꼴: Pretendard → Noto Sans KR → 시스템 산세리프
- 페이지 제목 18px 800 / 섹션 제목(고른 상권 — 한식) 20px 800
- 큰 숫자 22px 800 + 단위 13px 600 (예: **3,450**만 원)
- 라벨 칸 제목 14px 700 흰색, 부제 11px 흰색 75%
- 보조 설명 12px `--muted`, 각주 12px `--muted`

## 3. 레이아웃

- 최대 너비 1360px, 흰 배경
- 상단 바: 왼쪽 제목 + 노란 배지, 오른쪽 `대분류 [▼]` `중분류 [▼]` (라벨이 셀렉트 왼쪽)
- 탭: `상권 비교 n곳` | `상권 상세` — 선택된 탭은 위·좌·우 테두리가 있는 카드형, 아래는 구분선
- 비교 표: **라벨 1열 + 상권 3열** 격자 (비율 1.15 : 2 : 2 : 2, 간격 16px)
  - 열 머리글: 남색 막대(`후보 상권`, `상권 A/B/C`), 비어 있는 상권은 흐린 남색
  - 섹션 구분: 남색 굵은 작은 글씨 + 오른쪽으로 이어지는 얇은 선 (예: `매출 ───────`)
- 칸 모서리 6px, 상자 모서리 10px, 그림자는 하이라이트 라벨에만

## 4. 구성 요소

| 요소 | 모양 |
|---|---|
| 라벨 칸 | 남색 배경, 가운데 정렬, 제목 + 부제, 필요하면 노란 `데이터 확보 시` 태그 |
| 값 칸 | 흰 배경, 1px `--line` 테두리, 큰 숫자 + 보조 설명 |
| 비교 막대 | 두 줄: 남색 막대 `이 상권`, 회색 막대 `서울 보통 n` |
| 태그 | 작은 사각 칩: `가장 높음`(라벤더), `유리`(초록), `아쉬움`(주황), `보통`(회색) |
| 하이라이트 행 | 라벨: 남색 그라데이션 + 노란 `핵심 요약` 태그 / 칸: 2px 남색 테두리 + 연한 라벤더 배경, 칩 2개(▲·▼) → 얇은 선 → 굵은 한 문장(키워드 남색) |
| 5가지 요인 상자 | 연한 배경 상자 안에 제목(업종 칩 2개) + 부제 + 카드 5장 가로 배치 + 하단 고정 문구 |
| 요인 카드 | 흰 카드: 숫자 원 → 요인명 → 관계 모양 선(오르는/내려가는/볼록) → `어떤 값이에요` → `매출과의 관계` |
| 지도 칸 | 밝은 회색 지도 + 점선 남색 경계(라벤더 채움), 왼쪽 위 흰 이름표(이름 / 구·넓이·업종 가게 수), 아래 `변경` · `삭제` 버튼 (상세는 상단 `상권 상세` 탭으로만 이동) |
| 시간대 띠 | 같은 크기 네모를 가로로, 값이 클수록 진한 남색, 가장 큰 칸이 제목 |
| 해시태그 | 라벤더 배경의 둥근 알약 칩 |
| 각주 | 페이지 맨 아래, 얇은 선 위에 점 목록 |

## 5. 문구 규칙

- "~인 편이에요", "~일 수 있어요", "~맞아요"로 끝낸다
- 인과·보장 표현("이렇게 하면 매출이 오른다", "추천해요")을 쓰지 않는다
- 숫자는 칩·값 칸에만, 문장에서 반복하지 않는다
